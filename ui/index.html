SESSION CONTROL

結束終端？
QUICK GUIDE

讓每個測試，都有自己的位置。

  1. 選擇格數設定列、欄數，最多同時顯示 16 格。
  2. 選擇本機資料夾每格按「從資料夾啟動」，選取後即以該資料夾啟動 CMD／PowerShell。齒輪設定內也可選取資料夾，再儲存供下次啟動使用。
  3. 啟動並操作點選終端輸入指令；也可一次啟動所有可見格。執行中按「下次啟動資料夾」只會設定下次啟動位置，測試會繼續執行。

Ctrl+C中斷前景指令，例如持續 Ping。

Ctrl+Shift+C複製選取文字。

Ctrl+Shift+V貼上剪貼簿文字。

Esc離開單格放大，返回網格。

每格顯示的「啟動資料夾」是已儲存的設定；終端啟動後仍可用 cd 等指令自行切換。資料夾選擇在本機進行，不會上傳檔案。

縮小格數會保留隱藏格的測試。關閉格子或離開管理器會結束對應終端程序。匯入配置不會自動啟動指令。
