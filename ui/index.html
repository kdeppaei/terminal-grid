QUICK GUIDE

讓每個測試，都有自己的位置。

  1. 選擇格數設定列、欄數，最多同時顯示 16 格。
  2. 設定每格按齒輪設定名稱、CMD／PowerShell、工作目錄與啟動指令。
  3. 啟動並操作點選終端輸入指令；也可一次啟動所有可見格。

Ctrl+C中斷前景指令，例如持續 Ping。

Ctrl+Shift+C複製選取文字。

Ctrl+Shift+V貼上剪貼簿文字。

Esc離開單格放大，返回網格。

縮小格數會保留隱藏格的測試。關閉格子或離開管理器會結束對應終端程序。匯入配置不會自動啟動指令。

此版本使用 Windows ConPTY 整合終端，無法接管已在其他視窗執行的 CMD／PowerShell。請在這裡啟動新終端。
