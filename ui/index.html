QUICK GUIDE

讓每個測試，都有自己的位置。

  1. 選擇格數設定列、欄數，最多同時顯示 16 格。
  2. 選擇本機資料夾每格按「從資料夾啟動」，選取後即以該資料夾啟動 CMD／PowerShell。齒輪設定內也可選取資料夾，再儲存供下次啟動使用。
  3. 啟動並操作點選終端輸入指令；也可一次啟動所有可見格。執行中按「下次啟動資料夾」只會設定下次啟動位置，測試會繼續執行。

Ctrl+C中斷前景指令，例如持續 Ping。

Ctrl+Shift+C複製選取文字。

Ctrl+Shift+V貼上剪貼簿文字。

右鍵有框選就複製並解除框選；無框選就貼上。

Shift＋右鍵 / F10開啟完整終端選單，也可按每格 ⋯。

Esc關閉選單，或離開單格放大返回網格。

每格顯示的「啟動資料夾」是已儲存的設定；終端啟動後仍可用 cd 等指令自行切換。資料夾選擇在本機進行，不會上傳檔案。

縮小格數會保留隱藏格的測試。關閉格子或離開管理器會結束對應終端程序。匯入配置不會自動啟動指令。

此版本使用 Windows ConPTY 整合終端，無法接管已在其他視窗執行的 CMD／PowerShell。請在這裡啟動新終端。

WI-FI AWARE

NAN／NDP 雙手機流程

依提示在兩台手機建立 NDP。DUT2 收到 IPv6 Ping 回覆後，即可選擇傳輸測試。

選擇兩台 USB 手機與本機 App 操作設定檔。儲存後，主畫面的 NAN＋Ping 會直接建立連線並持續 Ping。

自訂測項的人工檢查點

檢查點會寫入流程和匯出的 .tgridflow。請依內容決定分享範圍。

介面填 auto 時，建立 NDP 後偵測兩端 Wi-Fi Aware 介面。每次重啟 Ping／Traffic 都重新查 DUT1 IPv6。% 後使用 DUT2 發送介面。若有多個候選，請手動指定。手機兩端需已有相同系列的 iperf。

Ping 分頁會持續保活，可按 Ctrl+C 停止。Quick Share 由手機操作，實際傳輸路徑依手機決定。
